# Jucileia Portfolio Hub

Cópia de segurança do código-fonte do portfólio pessoal.

## Estrutura

- `dist/index.html`: estrutura da página
- `dist/styles.css`: estilos visuais
- `dist/app.js`: interações da página
- `dist/assets/`: imagens utilizadas pelo site
- `.openai/hosting.json`: configuração original de hospedagem

Esta cópia é mantida separada do site publicado. Não publique ou altere a configuração de hospedagem sem revisar antes.
